# KompasRelink

**Массовая замена путей к деталям и подсборкам в файлах КОМПАС-3D.**

Проект переехал с сервера на диск, папку переименовали или архив скопировали домой, а сборки
открываются с красными крестами: «файл не найден». Вместо того чтобы перецеплять каждую деталь
вручную, укажите папку и правило замены, например `\\metall\Проекты` → `G:\Проекты`.
KompasRelink пройдёт по всем подпапкам и исправит ссылки во всех документах сразу.

### [⬇ Скачать KompasRelink.exe](https://github.com/Ramilq1989/KompasRelink/releases/latest)

Устанавливать ничего не нужно: скачайте и запустите.

## Возможности

- Обрабатывает **сборки (.a3d), детали (.m3d), чертежи (.cdw), спецификации (.spw) и фрагменты (.frw)**
  во всех подпапках на любую глубину.
- **Пробный прогон.** Кнопка «Проверить» показывает, какие ссылки изменятся, и ничего не записывает.
- **Проверка результата.** Если по новому пути файла нет, программа помечает ссылку «НОВОГО ФАЙЛА НЕТ».
- **Версия файлов сохраняется.** Файл v23, обработанный в КОМПАС v24, останется v23 и откроется на работе.
  Можно принудительно сохранить всё в нужной версии.
- **Резервные копии** изменённых файлов с сохранением структуры папок. Откат делается простым копированием.
- **Отчёт в CSV** (открывается в Excel): каждый файл, старая и новая ссылка, статус.
- **Несколько правил замены сразу**. Слэши `/` и `\` равнозначны, регистр не важен.
  Правило `//metall` не заденет `//metall2`.
- **Командная строка** для bat-файлов и запуска по расписанию.

## Требования

- Windows 10 или 11 (.NET Framework 4 уже есть в системе).
- КОМПАС-3D **v20 или новее**. Проверено на v24.

## Как пользоваться

1. Закройте в КОМПАСе сборки и чертежи из нужной папки.
2. Запустите `KompasRelink.exe` и выберите папку, например `G:\Проекты`.
3. Впишите замены, по одной в строке:

   | Что нужно | Строка замены |
   |---|---|
   | Весь сервер на диск G: | `//metall=G:` |
   | Одну папку сервера | `//metall/Проекты=G:/Проекты` |
   | С одного диска на другой | `D:/Архив=G:/Архив` |
   | С диска обратно на сервер | `G:/Проекты=//metall/Проекты` |

4. Нажмите **«Проверить»** и просмотрите журнал.
5. Нажмите **«Заменить»**. Перед записью программа сделает резервные копии.

Подробная инструкция с ответами на частые проблемы лежит в [Инструкция.html](Инструкция.html).

### Командная строка

```bat
KompasRelink.exe G:\Проекты --map "//metall=G:"                 :: пробный прогон
KompasRelink.exe G:\Проекты --map "//metall=G:" --apply         :: запись
```

| Ключ | Значение |
|---|---|
| `--map СТАРЫЙ=НОВЫЙ` | Правило замены, можно указать несколько раз |
| `--apply` | Записать изменения (без него только проверка) |
| `--save-version keep / current / 23` | Версия сохранения файлов, по умолчанию `keep` |
| `--no-backup` | Не делать резервные копии |

## Для разработчиков

| Файл | Назначение |
|---|---|
| `src/KompasRelink.cs`, `src/KompasLibrary.cs` | Программа с интерфейсом (C#, .NET Framework 4, COM API КОМПАС-3D) |
| `build.bat` | Сборка `KompasRelink.exe` и `KompasRelinkLib.dll` штатным `csc.exe`, Visual Studio не нужна |
| `relink.py`, `relink.bat` | Тот же функционал на Python (`pip install pywin32`) |
